✅ 第一步：打开工具

在这个文件夹中找到 dist 文件夹，用浏览器打开里面的 index.html 文件即可！

📁 第二步：上传Excel文件

点击或拖拽您的Excel文件到上传区域，工具会自动读取并显示数据。

🎨 第三步：分析和可视化

选择您需要的字段，查看各种图表和统计分析结果！

📝 重要提示

• 支持格式：.xlsx 和 .xls 文件
• 完全离线使用，无需联网
• 所有数据都在您本地处理，安全放心

🔧 如果想构建exe安装包

1. 安装 Node.js（从 nodejs.org 下载）
2. 在文件夹中打开命令行
3. 运行：npm install --legacy-peer-deps
4. 运行：npm run electron:build
