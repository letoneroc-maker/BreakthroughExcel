# Excel数据分析工具

一个功能强大的Excel数据分析工具，用于处理Excel文件、提取字段、进行数据操作和可视化分析。

## 功能特点

- **数据处理**：支持上传多个Excel文件，提取字段，拖拽预览，字段排序，函数运算
- **数据可视化**：支持多种图表类型（柱状图、折线图、饼图等），数据预览，统计分析
- **导出功能**：将处理后的数据导出为新的Excel文件，保存配置方便下次使用

## 技术栈

- 前端：React@18 + TypeScript + Tailwind CSS + Vite
- 数据处理：ExcelJS
- 数据可视化：Chart.js
- 状态管理：Zustand
- 构建工具：Electron (支持桌面应用)

## 安装和运行

### 开发模式

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 构建桌面应用

```bash
# 构建并打包为桌面应用
npm run electron:build
```

构建完成后，可执行文件将生成在 `dist-electron` 目录中。

## 使用说明

1. **数据处理页面**：上传Excel文件，从文件中提取字段，将字段拖拽到预览区域查看数据
2. **数据可视化页面**：选择图表类型，查看数据可视化效果和统计分析
3. **导出页面**：将处理后的数据导出为Excel文件，保存配置以便下次使用

## 系统要求

- Windows 7+ 或 macOS 10.13+
- 至少 4GB 内存
- 支持现代浏览器（Chrome、Firefox、Safari、Edge）

## 离线使用

本应用支持离线使用，无需联网即可运行所有功能。
